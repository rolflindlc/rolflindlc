# Hi, I'm Daniel 👋

**Web application development student (DAW) in Valencia, Spain**, looking for a **100-hour internship from around
May 2027** in **game development, game design, backend or databases**. Online as **Rolflin**.

I love designing systems: classes, races, combat rules, balance. I turn those designs into Minecraft mods and
my own games, and I'm learning to build them properly along the way.

## 🔨 Currently working on

- **Rolflin's Rites & Paths** and **Improved Armor**: getting both to a stable release for CurseForge. They started
  as mods for a server with my friends and classmates.
- **Pixel art** for Rites & Paths, replacing its placeholder textures.
- **Cruxifiction**, my turn-based game in Godot, which I program by hand to learn.
- A **Roblox** game in Luau (unreleased).
- Learning **3D modeling** with Blockbench and Blender.
